# 计算机基础知识速查手册

## 什么是操作系统

操作系统是管理计算机硬件与软件资源的系统软件，它是用户和计算机硬件之间的接口，也是计算机系统中最基本、最重要的系统软件。

操作系统的主要功能包括：
- 进程管理：负责进程的创建、调度、同步与通信
- 内存管理：负责内存的分配与回收、地址映射、虚拟内存
- 文件管理：负责文件的组织、存储、检索与保护
- 设备管理：负责输入输出设备的分配、调度与控制

常见的操作系统有 Windows、Linux、macOS，以及移动端的 Android、iOS。

## 进程与线程的区别

进程是资源分配的基本单位，线程是 CPU 调度的基本单位。

关键区别：
1. 进程拥有独立的地址空间，线程共享所属进程的地址空间
2. 进程间切换开销大，线程切换开销小
3. 一个进程崩溃不会影响其他进程，但一个线程崩溃可能导致整个进程崩溃
4. 进程间通信需要 IPC 机制，线程间可以直接读写共享内存

## 什么是死锁

死锁是指多个进程因争夺资源而造成的一种互相等待的现象，若无外力作用，它们都将无法继续推进。

死锁产生的四个必要条件：
1. 互斥条件：资源同一时刻只能被一个进程使用
2. 请求与保持条件：进程已持有资源，又请求新资源
3. 不可剥夺条件：已分配的资源不能被强制剥夺
4. 循环等待条件：进程间形成头尾相接的循环等待链

预防死锁的方法就是破坏这四个条件中的任意一个。

## 数据库事务的 ACID 特性

事务是数据库操作的最小工作单元，具有四个特性：

- 原子性（Atomicity）：事务要么全部执行，要么全部不执行
- 一致性（Consistency）：事务执行前后，数据库都处于一致状态
- 隔离性（Isolation）：并发事务之间互不干扰
- 持久性（Durability）：事务一旦提交，对数据库的修改是永久的

## HTTP 与 HTTPS 的区别

HTTP 是超文本传输协议，HTTPS 是在 HTTP 基础上加入 SSL/TLS 加密层的安全版本。

主要区别：
1. HTTPS 需要 CA 证书，HTTP 不需要
2. HTTPS 传输内容加密，HTTP 明文传输
3. HTTPS 默认端口 443，HTTP 默认端口 80
4. HTTPS 能防止数据被窃听和篡改

## 排序算法时间复杂度

常见排序算法的时间复杂度对比：
- 冒泡排序：O(n²)
- 选择排序：O(n²)
- 插入排序：O(n²)
- 快速排序：平均 O(n log n)，最坏 O(n²)
- 归并排序：O(n log n)
- 堆排序：O(n log n)

其中快速排序在平均情况下表现最好，归并排序是稳定的排序算法。
